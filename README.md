# Uni-Biz Hub - Campus E-Commerce Platform

Uni-Biz Hub is a responsive frontend web application designed for university student entrepreneurs to showcase and sell products across campus.

## Project Structure
- `index.html` - Home page featuring search bar, product catalog, and dynamic category filtering.
- `category.html` - Product details page with interactive quantity selector and customer reviews.
- `login.html` - Account login page with role switcher and real-time JavaScript form validation.
- `style.css` - Custom styling and theme layout.
- `script.js` - Dynamic JavaScript behaviors (form validation, smooth scrolling, interactive updates).

## Features Implemented
- Responsive design using Bootstrap 5 grid and custom CSS.
- Navigation bar and footer present on all pages.
- Dynamic search and live category filtering.
- Client-side form validation for email and password fields.

## Setup Instructions
1. Clone or download the repository.
2. Open `index.html` in any web browser.
